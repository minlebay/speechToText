# Voice2Text

Приложение для голосового ввода текста в Linux. Живёт в системном трее, записывает голос по горячей клавише, транскрибирует и вставляет текст в активное окно.

## Возможности

- Глобальная горячая клавиша для начала/остановки записи
- Три движка транскрипции на выбор:
  - **Whisper** (faster-whisper) — локально, офлайн, бесплатно
  - **Gemini** — облако, требует API ключ, умеет чистить текст от слов-паразитов
  - **Google Speech-to-Text** — облако, требует сервисный аккаунт GCP
- Поддержка смешанной речи (русский + английский)
- Два режима вывода: вставка в активное окно или копирование в буфер обмена
- Выбор устройства записи (микрофона) с автоопределением подключения/отключения
- Визуальный оверлей поверх всех окон во время записи/обработки — иконка микрофона
  со столбиками, реагирующими на громкость голоса, и настраиваемым положением на экране
- Живая транскрипция: распознанный текст можно показывать в оверлее прямо во время записи,
  не дожидаясь остановки
- Настройки через контекстное меню трея

## Требования

- Linux (X11, KDE/GNOME)
- Python 3.10+
- Системные пакеты:

```bash
sudo apt install xdotool portaudio19-dev python3-venv
```

## Установка

Приложение устанавливается из `.deb`-пакета (см. каталог `deb/`):

```bash
sudo apt install ./deb/voice2text_<версия>_amd64.deb
```

Пакет автоматически:

- Создаст виртуальное окружение в `/usr/share/voice2text/`
- Установит все Python-зависимости
- Создаст команду `voice2text` в `/usr/local/bin/`
- Создаст `.desktop` файл для меню приложений

## Запуск

```bash
voice2text
```

## Настройка движков

### Whisper (по умолчанию)

Работает из коробки, без дополнительной настройки. При первом запуске скачает модель (~75 МБ для `base`).

Доступные модели:

| Модель   | RAM     | Качество     |
|----------|---------|--------------|
| tiny     | ~40 МБ  | базовое      |
| base     | ~75 МБ  | хорошее      |
| small    | ~250 МБ | отличное     |
| medium   | ~800 МБ | высокое      |
| large-v3 | ~3 ГБ   | максимальное |

### Gemini

Добавьте в `~/.bashrc`:

```bash
export GEMINI_API_KEY_TTS="ваш_ключ"
```

### Google Speech-to-Text

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Cloud Speech-to-Text API
3. Создайте сервисный аккаунт и скачайте JSON-ключ
4. Добавьте в `~/.bashrc`:

```bash
export GOOGLE_APPLICATION_CREDENTIALS="/путь/к/service-account.json"
```

## Использование

1. Запустите `voice2text` — в трее появится значок микрофона
2. Нажмите горячую клавишу (по умолчанию `Ctrl+Shift+H`) — начнётся запись (красный значок)
3. Нажмите горячую клавишу ещё раз — запись остановится, начнётся транскрипция (фиолетовый значок)
4. Текст будет вставлен в активное окно (или скопирован в буфер обмена)

### Состояния индикатора

- Синий — готов к записи
- Красный (с пульсацией) — идёт запись
- Фиолетовый (с вращающейся дугой) — транскрипция

### Оверлей

Если включён в настройках, поверх всех окон по центру экрана (или в выбранном углу/стороне)
появляется небольшой полупрозрачный индикатор во время записи и обработки: иконка микрофона
в круге, окружённая столбиками, которые реагируют на громкость голоса в реальном времени.
При включённой живой транскрипции под иконкой также показывается распознанный текст,
обновляющийся прямо во время записи (пересчитывается каждые ~2.5 секунды), а не только
после её остановки.

### Настройки

Правый клик по иконке в трее → Настройки:

- **Горячая клавиша** — комбинация клавиш (формат pynput, например `<ctrl>+<alt>+h`)
- **Режим вывода** — `paste` (вставка через Ctrl+V) или `clipboard` (только буфер обмена)
- **Язык** — основной язык речи (`ru`, `en` и т.д.)
- **Движок** — `whisper`, `gemini` или `google_stt`
- **Whisper модель** — размер модели (только для движка whisper)
- **Gemini модель** — конкретная модель Gemini (только для движка gemini)
- **Очищать текст от слов-паразитов** — постобработка текста Gemini (убирает «э-э», «ну», «короче» и т.п.)
- **Устройство записи** — конкретный микрофон или системное по умолчанию
- **Показывать оверлей во время записи** — включает визуальный индикатор (см. выше)
- **Показывать распознанный текст в реальном времени в оверлее** — живая транскрипция
  (доступно только при включённом оверлее)
- **Положение оверлея** — по центру экрана, в одном из четырёх углов, либо по центру
  сверху/снизу/слева/справа

## Файлы

| Путь | Описание |
|------|----------|
| `/usr/share/voice2text/` | Установленное приложение и venv |
| `/usr/local/bin/voice2text` | Скрипт запуска |
| `~/.config/voice2text/config.json` | Настройки |
| `~/.config/voice2text/voice2text.log` | Лог-файл |

## Удаление

```bash
sudo apt remove voice2text
```

Конфиг в `~/.config/voice2text/` сохраняется.

## Структура проекта

```text
voice2text/
  __init__.py
  __main__.py       # Точка входа
  app.py            # UI, системный трей, горячие клавиши, настройки
  config.py         # Загрузка/сохранение конфига, логирование
  recorder.py       # Запись аудио через parecord (PulseAudio/PipeWire)
  transcriber.py    # Транскрипция (whisper/gemini/google_stt)
  icons.py          # Иконки трея (idle/recording/transcribing)
  overlay.py        # Визуальный оверлей и индикатор уровня голоса
  assets/           # SVG-иконка приложения
deb/                # Сборки .deb-пакета для установки
requirements.txt    # Python-зависимости
```
