# Voice2Text

Приложение для голосового ввода текста в Linux. Живёт в системном трее, записывает голос по горячей клавише, транскрибирует и вставляет текст в активное окно.

## Возможности

- Глобальная горячая клавиша для начала/остановки записи
- Четыре движка транскрипции на выбор:
  - **Whisper** (faster-whisper) — локально, офлайн, бесплатно
  - **Gemini** — облако, требует API ключ, умеет чистить текст от слов-паразитов
  - **Google Speech-to-Text** — облако, требует сервисный аккаунт GCP
  - **Deepgram** (Flux / Nova-3) — облако, требует API ключ; Flux распознаёт потоково, прямо во время записи
- Поддержка смешанной речи (русский + английский)
- Два режима вывода: вставка в активное окно или копирование в буфер обмена
- Выбор устройства записи (микрофона) с автоопределением подключения/отключения
- Визуальный оверлей поверх всех окон во время записи/обработки — иконка микрофона
  со столбиками, реагирующими на громкость голоса, и настраиваемым положением на экране
- Живая транскрипция: распознанный текст можно показывать в оверлее прямо во время записи,
  не дожидаясь остановки
- Настройки через контекстное меню трея

## Требования

- Linux: X11 (KDE/GNOME) или Wayland (KDE Plasma)
- Python 3.10+
- Системные пакеты:

```bash
sudo apt install xdotool xclip wl-clipboard portaudio19-dev python3-venv
```

Для хранения API-ключей нужен KDE Wallet (`kwalletd6`/`kwalletd5`, на KDE
установлен по умолчанию). В окружениях без KWallet используется Secret Service
(`secret-tool` из пакета `libsecret-tools`).

### Wayland

Под Wayland xdotool/xclip и перехват клавиш через pynput видят только X11-окна,
поэтому приложение переключается на другие механизмы:

- **Горячие клавиши** регистрируются в KDE (KGlobalAccel) и работают в любом окне.
  Они появятся в «Параметры системы → Комбинации клавиш» как Voice2Text, но задавать
  их нужно в настройках самого приложения — при запуске оно перезаписывает значения KDE.
  В других Wayland-окружениях без KGlobalAccel остаётся pynput, и хоткеи срабатывают
  только в X11-приложениях.
- **Вставка** — Ctrl+V через виртуальную клавиатуру `/dev/uinput`. Пакет ставит
  udev-правило `70-voice2text-uinput.rules`, открывающее uinput пользователю активной
  сессии (такое же ставит `steam-devices`).
- **Буфер обмена и выделение** — через `wl-copy` / `wl-paste`.
- Окна приложения (оверлей, настройки) работают через XWayland: только так оверлей
  можно поставить в нужное место поверх окон, не забирая фокус, и получить блюр KWin.

## Установка

Приложение устанавливается из `.deb`-пакета (см. каталог `deb/`):

```bash
sudo apt install ./deb/voice2text_<версия>_amd64.deb
```

Пакет автоматически:

- Создаст виртуальное окружение в `/usr/share/voice2text/`
- Установит все Python-зависимости
- Создаст команду `voice2text` в `/usr/local/bin/`
- Создаст `.desktop` файл для меню приложений
- Поставит udev-правило для `/dev/uinput`, без которого не работает вставка под Wayland

## Запуск

```bash
voice2text
```

## Настройка движков

### Whisper (по умолчанию)

Работает из коробки, без дополнительной настройки. При первом запуске скачает модель (~75 МБ для `base`).

Доступные модели:

| Модель   | RAM     | Качество     |
|----------|---------|--------------|
| tiny     | ~40 МБ  | базовое      |
| base     | ~75 МБ  | хорошее      |
| small    | ~250 МБ | отличное     |
| medium   | ~800 МБ | высокое      |
| large-v3 | ~3 ГБ   | максимальное |

### API-ключи

Ключи и JSON сервисного аккаунта хранятся в **KDE Wallet** и задаются в
«Настройки → API-ключи». В `config.json`, переменные окружения и командную строку
они не попадают. Сохранённые значения никогда не показываются в интерфейсе —
поле можно только заменить новым значением или удалить ключ.

Если KWallet в системе недоступен (например, в GNOME), приложение использует
Secret Service через `secret-tool`; на KDE всё хранится в KWallet.

### Gemini

1. Получите API-ключ в [Google AI Studio](https://aistudio.google.com/)
2. Откройте «Настройки → API-ключи» и вставьте ключ в поле **Gemini API ключ**

### Google Speech-to-Text

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включите Cloud Speech-to-Text API
3. Создайте сервисный аккаунт и скачайте JSON-ключ
4. В «Настройки → API-ключи» укажите путь к JSON-файлу в поле
   **Google сервисный аккаунт** (файл будет прочитан и сохранён в KWallet)

### Deepgram

1. Получите API-ключ в [Deepgram Console](https://console.deepgram.com/)
2. Откройте «Настройки → API-ключи» и вставьте ключ в поле **Deepgram API ключ**

Доступные модели:

- `flux-general-multi` (по умолчанию) — потоковое распознавание: звук уходит в Deepgram по WebSocket
  прямо во время записи, текст обновляется пословно (виден в оверлее при включённом «реальном времени»),
  а итог готов практически сразу после остановки. Если стрим оборвался, запись повторно
  отправляется обычным запросом в `nova-3`.
- `flux-general-en` — то же потоковое распознавание, но модель строго английская.
- `nova-3` — запись целиком отправляется после остановки. С включённым «реальным временем»
  тоже работает через стрим.

Выбор языка (настройка «Язык Deepgram») зависит от модели, и общее поле «Язык»
для Deepgram не используется:

- **`nova-3`** — автоопределение, русский, английский, сербский, немецкий.
  «Только …» включает монолингвальный режим (`language=ru`, `language=sr` и т.д.):
  другие языки не распознаются. «Автоопределение» — `language=multi`, Deepgram сам
  выбирает из 55 поддерживаемых языков.
- **`flux-general-multi`** — автоопределение и любой из 10 языков модели
  (en, es, fr, de, hi, ru, pt, ja, it, nl). Язык передаётся как `language_hint`
  и сильно смещает модель, но не запрещает остальные языки из этой десятки.
- **`flux-general-en`** — только английский, выбор языка не требуется.

Для строгого ограничения English-only удобно выбирать `flux-general-en`: украинский,
арабский и прочие языки вне набора модели в нём появиться не могут.

## Использование

1. Запустите `voice2text` — в трее появится значок микрофона
2. Нажмите горячую клавишу (по умолчанию `Ctrl+Shift+H`) — начнётся запись (красный значок)
3. Нажмите горячую клавишу ещё раз — запись остановится, начнётся транскрипция (фиолетовый значок)
4. Текст будет вставлен в активное окно (или скопирован в буфер обмена)

### Состояния индикатора

- Синий — готов к записи
- Красный (с пульсацией) — идёт запись
- Фиолетовый (с вращающейся дугой) — транскрипция

### Оверлей

Если включён в настройках, поверх всех окон по центру экрана (или в выбранном углу/стороне)
появляется небольшой полупрозрачный индикатор во время записи и обработки: иконка микрофона
в круге, окружённая столбиками, которые реагируют на громкость голоса в реальном времени.
При включённой живой транскрипции под иконкой также показывается распознанный текст,
обновляющийся прямо во время записи (пересчитывается каждые ~2.5 секунды), а не только
после её остановки.

### Настройки

Правый клик по иконке в трее → Настройки. Настройки разбиты на три вкладки.

**Вкладка «Распознавание»** — запись, вывод и движок:

- **Горячая клавиша** — комбинация клавиш (формат pynput, например `<ctrl>+<alt>+h`)
- **Горячая клавиша (режим кода)** — отдельная комбинация для генерации кода через Gemini
- **Режим вывода** — `paste` (вставка через Ctrl+V) или `clipboard` (только буфер обмена)
- **Не показывать уведомления KDE** — скрывает всплывающие уведомления о начале записи
  и готовом тексте (предупреждения и ошибки остаются)
- **Устройство записи** — конкретный микрофон или системное по умолчанию
- **Движок** — `whisper`, `gemini`, `google_stt` или `deepgram`
- **Язык** — основной язык для Whisper, Gemini и Google STT (Deepgram его не использует)
- **Whisper модель** — размер модели (показывается только для движка whisper)
- **Gemini модель** — конкретная модель Gemini (только для gemini)
- **Deepgram модель** — `flux-general-multi`, `flux-general-en` или `nova-3` (только для deepgram)
- **Язык Deepgram** — список зависит от модели: автоопределение и поддерживаемые ею языки
  (для `nova-3` — русский, английский, сербский, немецкий)
- **Очищать текст от слов-паразитов** — постобработка текста Gemini (только для gemini)

**Вкладка «Внешний вид»** — оверлей и иконка:

- **Показывать оверлей во время записи** — включает визуальный индикатор (см. выше)
- **Показывать распознанный текст в реальном времени** — живая транскрипция
  (доступно только при включённом оверлее)
- **Положение**, **тема**, **форма** и **прозрачность стекла** оверлея
- **Монохромная иконка** в трее и её цвет

**Вкладка «API-ключи»** — Gemini, Deepgram и JSON сервисного аккаунта Google
(хранятся в KWallet, сохранённые значения не отображаются).

## Удаление

```bash
sudo apt remove voice2text
```

Конфиг в `~/.config/voice2text/` сохраняется.

## После обновления системы

venv привязан к версии системного Python. Если она сменилась (например, при обновлении
Ubuntu), `voice2text` не запустится и покажет уведомление — пересоберите окружение:

```bash
sudo dpkg-reconfigure voice2text
```

## Структура проекта

```text
voice2text/
  __init__.py
  __main__.py       # Точка входа
  app.py            # UI, системный трей, горячие клавиши, настройки
  config.py         # Загрузка/сохранение конфига, логирование
  desktop.py        # Буфер обмена, выделение, эмуляция клавиш (X11/Wayland)
  hotkeys.py        # Глобальные горячие клавиши через KDE KGlobalAccel (Wayland)
  recorder.py       # Запись аудио через parecord (PulseAudio/PipeWire)
  transcriber.py    # Транскрипция (whisper/gemini/google_stt/deepgram)
  deepgram_stream.py # Потоковое распознавание Deepgram (WebSocket)
  icons.py          # Иконки трея (idle/recording/transcribing)
  overlay.py        # Визуальный оверлей и индикатор уровня голоса
  assets/           # SVG-иконка приложения
deb/                # Сборки .deb-пакета для установки
requirements.txt    # Python-зависимости
```
